# 独立FFN2真实输入诊断

三份真实block capture提供GELU/ACT与R2输入，权重/调制原样。Torch_region为FFN2 Linear＋BF16结果＋门控残差3；Serial与SplitK调用相同计算基元，差异为K段串行或跨CTA计算并按序提交。两臂预分配输出与队列，kernel内部初始化状态；原Torch区域使用框架原分配。双方eager、无Graph。

这不是纯GEMM或整层/机器人速度。纯Torch Linear另列背景，不能作融合自有区域的同口径分母。诊断kernel保留整层shared容量/线程数，但编译后寄存器/local可能不同，不能假设完全复制整层资源成本。
