# R2：保留两个FFN2分段的并行计算

R1为保守就绪条件：第二段连MMA也等待同一行块第一段24任务提交。R2将该依赖移到commit前，两段MMA可并行；FP32第二段暂存本CTA shared，与旧阶段版一致。此改动不改变MMA指令顺序、部分和BF16或最终bias/residual。

A100实测108常驻CTA，第二段最多48个CTA等待提交；其他至少60个CTA足够继续生产与第一段计算。每个CTA先完成自己静态分配的全部FFN1 tile，才可能持有消费者任务，不会持有未生产的必要ACT。无等待CTA持有必须由自己完成的第一段任务。96个消费者任务全部被领取后，空闲CTA可进入唯一出口grid屏障，避免持续轮询。

200种事件时序模拟均112生产/96消费恰好完成，部分和等待不超过48CTA；这不是通用所有GPU的保证，GPU核验固定当前108CTA配置，未来改变grid/分块需重审。GPU输出/状态验证仍是必需。原R1证据保留，本轮绝对截止不变。
