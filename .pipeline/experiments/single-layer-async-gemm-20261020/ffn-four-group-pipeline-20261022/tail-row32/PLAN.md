## 依赖与可证伪假设

H_R = GELU(X_R W1 + b1)，Y_R = H_R W2 + b2。K3072归约与原bias/BF16/GELU边界不变。FFN2仍按两段7168归约与BF16部分和提交。原128行和96有效行两个行块，每个通道半组28个生产tile；新组3为24个大tile加12个小tile，计数36。消费者仍96个partial任务，第二段仅提交时等待第一组完成。

拆分缩短单个尾部任务，但重复读取四块权重；还会增加设备函数和发布次数。并不预设一定更快。原Torch FFN1同样有112CTA；不能只依据任务数把性能差归因于末波。

仅更早完成第一行块、或部分通道tile，不保证整体收益。需要最后所需组更早就绪并使最后消费完成提前。若数值失败则不计时、不降低门；若整层退化则恢复R2。只有一个方案，无分块网格搜索。
