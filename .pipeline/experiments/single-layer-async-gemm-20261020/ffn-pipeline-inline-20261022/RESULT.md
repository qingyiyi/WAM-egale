# 外层 FFN 内联与尾块 K64 结果

当前两机研究入口采用 outer-inline + FFN1 tail K64。baseline、投机生产与原 tile 未修改；四项科学权限及 production_admitted 仍 false。

## 已观察

1. 仅将 action_ffn_pipeline 外层设备函数强制内联：同轮完整层延迟下降约 0.42% / 0.54% / 0.61%。这去除了单独函数的 ABI 边界，并没有消除全部 local 访问。静态 local 反而从 920B/线程变为 1016B；无本轮动态计数器证据，不能把静态指令差换算成可省墙钟。
2. 在已通过内联版本上，仅将 FFN1 的12个 M32×N256尾块 K32→K64、仍3级流水：同轮完整层再降 0.79% / 0.42% / 0.56%。主108块仍 M128×N256×K32，FFN2数学与依赖不改。debug末组就绪相对首组约86–88μs→60μs，支持尾部生产更快；这不是所有FFN分量均改善。
3. 每项均通过9真实签名+36结构控制，共225完整调用的有限逐位/状态门；真实计时与精度fixture身份6/6匹配。覆盖输出、中间值、输入、有效KV、RNG及重复/普通路径；不能推广为所有输入证明或闭环证书。

## 独立 FFN 测量的限制与负结果

两种外置FFN重放诊断均保存。第一种复制了forceinline子图，测得约1.01×；修正为单一FFN调用点后约0.90–0.91×。二者虽有限逐位/状态通过，但编译资源与完整层均变化（整层约0.7%–1.1%扰动），结果方向不同，不能择优宣称当前生产FFN已追平。当前生产独立FFN精确加速比 UNKNOWN。旧版本0.9182/0.9167/0.9161×仅属旧版本。

最新用户要求完整阶段表，本轮新增当前整层时间戳诊断和同真实中间输入的原Torch阶段Graph。自有含核内调度/同步，Torch阶段独立热缓存；必须注明边界差异与插桩扰动，不把其比值当作端到端收益分摊。
