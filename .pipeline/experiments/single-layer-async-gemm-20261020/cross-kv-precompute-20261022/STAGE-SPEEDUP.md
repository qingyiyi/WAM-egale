# 当前相对Torch加速比与逐阶段缺口

用户2026-10-22明确要求展示相对Torch加速比，不再以绝对耗时作为聊天阶段表的主要性能列。加速比统一定义为T_baseline/T_custom，>1更快、<1更慢。tile数与每tile工作量继续保留。原始时间仍在CSV与STAGE-TABLE中供追溯。

## 已有完整单层结果

双方预计算最终Cross K/V，同GPU、同真实输入、同Graph边界；先平均两个独立进程各自的时间中位数，再取比值。

|KV|原Torch静态缓存路径 / 自有|最强guarded缓存路径 / 自有|
|---|---:|---:|
|short|1.1824×|0.9265×|
|middle|1.7114×|0.8952×|
|long|2.7652×|0.8954×|

原Torch静态路径保留dense history attention；guarded为已有候选分组/shared-prefix强baseline，两者不可混名。自有相对原Torch更快，仍未追平强guarded。仅完整一层warm计时，不是30层、机器人任务或E2E。
