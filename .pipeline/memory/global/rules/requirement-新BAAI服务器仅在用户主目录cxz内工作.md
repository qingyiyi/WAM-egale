# 新服务器工作目录固定为 ~/cxz

在本次提供的BAAI新服务器上，所有项目代码、环境、依赖安装、缓存、下载、日志、数据、结果和作业临时文件均限定在登录账号的 `~/cxz` 及其子目录。路径按实际远端主目录展开，并检查真实路径，不能将本机或AutoDL的绝对路径直接套用。不得在其他用户目录、主目录其他位置或系统目录创建/修改项目文件，不改系统服务或全局环境。

允许为核查硬件和环境执行必要的只读系统信息查询；工作目录保持 `~/cxz`。新建项目环境时须显式将安装前缀及缓存/临时目录绑定到该目录，不能因工具默认值写入 `~/.cache`、`~/.conda` 或系统临时目录。SSH客户端身份文件继续留在原机器，私钥不复制到新服务器。

首次接入先只读核查、讨论分配；用户随后已明确批准[将已有研究迁入并核验后释放AutoDL](../requirements/decision-将已授权研究迁往BAAI并核验后释放AutoDL.md)。当前可在上述目录约束下完成必要环境、资产迁移与原授权任务接续，不因此获得全局安装、其他路径写入或额外科研范围的授权。

约束为用户明确要求，在本项目后续所有涉及该新服务器的会话持续有效；临时容量、占用和诊断结果放Cycle证据，不记成长期事实。
