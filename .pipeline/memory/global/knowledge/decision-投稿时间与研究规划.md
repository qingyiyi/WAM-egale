# 投稿时间与研究规划

目标CVPR2027，用户要求11/01 18:00北京时间前给老师完整中文稿，保留约半个月。

10/15核验官网注册/正文/补充AoE为2026-11-10/16/23，按日末换算北京时间11/11、11/17、11/24 19:59。独立abstract截止未单列，注册前锁摘要/标题/作者；投稿前再查官网及OpenReview。所有作者profile尽早处理，非机构邮箱新profile可能需两周。

网页端总计划仍在生成，不能当成已采纳方案。后续优先质量收口与真实verifier瓶颈证据，扩大质量期间可并行设计/profile/会话写作；新的算子实现与正式性能按已批准范围、质量及资源门推进。LIBERO100、第二模拟器/模型、真机是否必要尚待有证据的范围决策。

官方：https://cvpr.thecvf.com/Conferences/2027/Dates 、https://cvpr.thecvf.com/Conferences/2027/CallForPapers 。
