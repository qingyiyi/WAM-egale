# 成功率与性能分机执行，本机保留轻量工作区

已授权的机器人质量/成功率任务放在现有远端双A100；算子开发、精度与速度比较放在现有5090。原硬件结果分别标注，不跨卡混算性能。现有样本量、质量权限及A100预算不因此增加。

本机默认保留源码、HW、协议、完整轻量结果表、失败账本、必要构建说明及少量代表输入；大模型和历史完整tensor逐文件迁移、校验并落盘确认后立即释放该文件本地副本，不等待整批完成。未传完、变化或未确认的文件保留，并保留完整清单、远端原件和恢复入口。临时运行按当时具体授权安排，不自动恢复本机常规质量或正式计时。

清理先核当前依赖、归档或字节相同的副本，再保存原路径/归档路径/恢复方法和真实回收量。只在现有远端~/cxz下归档，不删除远端正在使用的资产，不改原tile、科学门、保护文件或投机源码。所有5090源码和必要结果仍回同步本机。
