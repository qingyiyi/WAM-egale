# 算子只保留两份主实现，投机侧代码不改

算子工作集中到独立目录，只维护baseline与optimized两份主实现，共享必要的验证/计时工具和第三方依赖。文件命名直观、代码尽量简洁，不再用多个版本目录并行堆积。迁移核验后删除无依赖的旧算子代码；历史结果和可追溯Git提交保留。

投机模型、训练、接受器、调度、配置、服务入口及其运行时依赖不修改。即使代码位于旧算子相关目录，只要被投机侧引用，就不纳入删除范围；不能为整理算子目录而调整投机import。远端既定评估继续运行。

先完成当前代码的真实30层替换验证和性能基线，再统一汇报并结合简化源码讲解。具体作业仍有独立预算、原始结果、清理记录；不把旧阶段截止重置，不把有限机制结果提升成机器人质量证书。
