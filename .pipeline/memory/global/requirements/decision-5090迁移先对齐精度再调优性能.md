# 5090先对齐精度再调优性能

用户明确将5090算子的当前工作顺序定为先修复数值差异，再考虑性能调优。以同卡当前原Torch实际调用为参照，先定位首个分歧，再核对完整单层输出、中间量、有效KV、输入及RNG；不把小相对误差视为自动通过，不为通过而降低原标准或更换更容易匹配的baseline。
