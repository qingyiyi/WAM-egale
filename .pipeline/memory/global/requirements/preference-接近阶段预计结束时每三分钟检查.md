# 接近预计阶段完成时再检查

根据实际最近完整episode耗时估计当前阶段结束窗口，接近该窗口时再按每3分钟检查。其余时间让既定任务和必要资源守护自动运行，停止额外的频繁状态查询与常规聊天汇报。阶段完成或发现异常后核对原件并及时报告。

此决定替代先前在整个运行期间每4～5分钟持续汇报的频率；原用户仍希望取得结果后及时获知。预计时间是随任务长度/CPU竞争变化的估计，不保证准时结束，下一阶段需重新估计。原四分钟偏好作为历史保留，不并行运行两套重复轮询。

只暂停/替换额外的metadata报告器，不停GPU实验、既定接续控制器或必要的独立资源guard。后台写记录不等于聊天已送达，不保证活动会话结束后的自动推送。原M17预算/截止/四false/失败不变。
