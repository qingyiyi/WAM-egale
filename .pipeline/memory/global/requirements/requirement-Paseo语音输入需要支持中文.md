# Paseo语音输入需要支持中文

用户希望直接使用 Paseo 的麦克风说中文，并得到中文转写。后续为用户配置或修复 Paseo 语音输入时，需要选择支持中文的识别后端；仅让默认英文模型下载成功不能满足这项需求。

本条适用于用户的 Paseo 工具配置，不改变 WAM 研究计划、GPU 资源授权或实验结果；不替代已有长期要求。
