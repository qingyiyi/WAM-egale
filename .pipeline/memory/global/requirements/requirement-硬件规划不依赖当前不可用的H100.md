# 硬件规划不依赖当前不可用的H100

当前用户没有H100资源，后续算子实验计划不能将H100当作已具备条件或必需前置。
用户仅询问H800可否作为替代；尚未提供该机、连接方式、新预算或执行授权。H800是可讨论的后续平台，不自动租卡、迁移或启动作业。现有A100本轮授权继续有效。

此记录不将助手建议的卡型排序提升为用户决定，不替代既有资源账本、独占要求或截止。
