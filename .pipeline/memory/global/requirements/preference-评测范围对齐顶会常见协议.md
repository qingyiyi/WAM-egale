# 评测范围与样本量按论文及官方基准明确命名

用户希望按主流顶会论文采用的基准范围规划完整评估，关注总体成功率、trace长度与实际端到端成本，不只看已知风险病例。选择范围时应核查原文和对应模型权重，不把100条episode、LIBERO-100的100种任务，以及Spatial/Object/Goal/Long四套混称。

“只做Long是否影响投稿”是需要证据评估的研究风险，不是自动获得其他suite权重、认可零样本替代或保证发表的结论。初态、训练/开发来源、随机种子、完整失败、冷/暖时间与硬件条件分开；具体运行以独立实验登记及用户最新资源授权为准。
