# 5090投机测速按套临时迁入，回传后清除权重

用户授权在现有RTX5090执行LIBERO与RoboTwin投机性能测量。沿已有冻结Target、TF和TF+PF2身份及等价reset优化，逐套核验计时边界、输入、实际执行与有效提交，保留失败和未知；不把调用减少或单层重放改称任务E2E。

5090数据盘有限，权重与必要评测资产只临时迁入本轮独立目录，优先按套轮换。每套结束先将结果、必要原始证据、源码/执行与清理收据传回本机并核验，随后删除该套远端临时权重/资产。最终删除本轮测试目录，不让权重转存到HF/cache等其他5090目录；下次需要再重新传输。结果回传失败时保留可恢复证据并报告，不静默删唯一原件。

清理仅限本轮拥有且已核验无活动依赖的目录/进程，不删除已保留的单层算子工作区、工具链或他人数据。用户授权本轮测速不修改旧FAILED、既有四项false、旧正式45chunk门、阈值、训练/测试身份或A100累计预算，不新增训练/环境。真实自然任务、完整推理重放、kernel/block成本分别标注。
