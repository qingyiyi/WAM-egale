# 任务完成前定期核验服务器运行与进度

对本项目仍未完成的已授权服务器作业，持续安排低开销健康巡检，不只在预计完成时检查。核对controller/worker的PID出生身份、日志/进度是否推进、完整终态与预算截止；PID存在或launcher退出都不能单独代表作业正常或研究完成。

当前执行选择为约每5分钟巡检，接近阶段终态时可更密；这是实现频率，不是把用户未给定的具体分钟数写成硬标准。发现停滞、退出、资源阻塞或阶段切换，及时在可用会话汇报实际变化与证据，不能一直沿用旧快照称“正在运行”。

巡检只读、CPU低开销，不额外占GPU、不修改既定科学配方/质量门或自动重试禁止重试的完整任务；原绝对截止和自有清理继续有效。新机所有项目文件、缓存与临时项仍限~/cxz；凭据不进HW/GitHub。后台巡检有独立预算、终态和本地记录，不承诺聊天工具不支持的离线主动推送。
