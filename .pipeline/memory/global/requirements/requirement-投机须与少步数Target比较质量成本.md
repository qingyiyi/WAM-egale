# 论文对照必须覆盖少步数Target

用户要求在论文证据中加入直接减少action去噪轮次的Target对照，并给出使用投机的实验依据。不能只与原50步Target比较就宣称投机有必要，不能预设TF优于更简单的少步数策略。

原50步Target与冻结TF连续/PF2仍保留。当前推荐新增25步与17步：分别代表减半和减少约三分之二；这是待登记的具体方案，不把用户的问句记作已经批准额外全量GPU作业。每种方案重新生成合法、完整积分到终点的σ网格，仅改变action步数；video、环境、reset bank、初始化与其他工程条件一致。

比较完整任务成功率、配对胜负、共同成功长度分布、全部任务失败800罚分，以及完整chunk/任务的真实成本。B2和B14调用不能等价计费；若需等成本点，仅在独立DEV预算内用实际耗时决定，不按TEST调点。不同σ网格下每scheduler更新代表的推进不同，不能只凭ΣT/Σg跨schedule宣布胜负。

解释边界：投机维持原网格，并以teacher验证/拒绝候选尝试减少串行耗时；少步数直接改变积分离散化。两者都需闭环验证，局部阈值不是轨迹或成功率保证。只有实测质量—成本权衡优于少步数强基线，才允许把它写成采用投机的理由；若少步数同质量更快，应如实收缩主张。

当前优先迁移与已有三臂完整研究；新增对照须独立登记清单、预算、终态及数据身份，不追改旧FAILED、旧门或四项false。本要求不授权视频投机、更多结构搜索或无限步数搜索。
