# 持续记录优化与可追溯证据

用户要求在研究推进中保存优化过程，供后续论文方法、消融和结果分析使用。沿现有HW研究记录维护简短证据索引，记录改动内容、动机、源码/版本身份、比较基线、输入与计时边界、精度覆盖、实测收益、限制及采用/回退状态。

正结果和负结果均保留；待验证解释与观察事实分列，未实现方案不写成已完成优化。单因素收益、组合收益和不同版本结果不可直接相乘；kernel、完整层、模型、机器人任务成本分别说明。不把已有库、缓存或通用实现技巧自动表述为新贡献。

当前算子入口为[M39优化证据索引](../../../experiments/single-layer-async-gemm-20261020/OPTIMIZATION-LEDGER.md)。索引引用原始报告和数据，不复制长日志，不新建本地论文初稿；后续中文论文段落仍在会话讨论，由用户整理。

来源为本次明确指令；补充既有证据与中文写作要求，无替代关系，不增加实验或GPU授权。
