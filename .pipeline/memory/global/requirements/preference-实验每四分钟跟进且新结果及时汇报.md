# 当前实验按四分钟主动跟进

本轮既定LIBERO完整研究运行期间，目标每4分钟核对并向用户报告一次实际进度；有阶段完成、新的完整结果、失败或资源异常时及时汇报，不必等下一周期。无新增完整结果时也说明当前阶段、完成量和变化，不把控制器启动或部分采集包装成最终结果。

在可持续执行的会话中保持跟进；后台程序写HW/JSON只代表记录，不等于聊天消息已送达。没有实际可用的对话唤醒/推送能力时，应明确其边界，不能在结束会话后保证继续主动发消息。用户无需重复询问原资源和实验授权。

汇报频率不扩展实验范围、GPU预算、截止或原质量权限，也不重置失败与清理账本。临时计数、时间和具体进程留Cycle/实验记录，不写成永久事实。
