# 有限独占窗口优先采集性能

本轮算子补测在当前剩余独占窗口内优先完成真实输入规模的性能采集，输入输出与精度验证可随后安排。实现应缩小重复量和独立进程数以服从资源窗口，采用独立登记的新性能协议；旧长重复协议按实际完成范围保留为PARTIAL，不重写其通过状态或挑选样本。

所有待验数值、有效KV和状态契约必须明确标为未完成，不能因为延后验证就默认PASS。已保存的真实输入、已完成原始数据和失败消耗保留。预留清理余量，在本轮登记的绝对释放时间前结束自有GPU作业；用户要求缩短窗口不构成追加GPU预算、降低旧质量门或开放正式TF任务性能。

性能采集窗口结束后的精度与完整输入输出验证，用户已明确允许在共享GPU上继续，并与性能结果统一汇报。该后续授权仅解除精度验证等待新独占窗口的依赖；不追溯延长原独占计时、不把共享阶段用时混入性能数据，也不改变原数值/质量门。先核验显存余量，独立登记有界验证作业与自有清理。
