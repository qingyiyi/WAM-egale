# 本轮保持现有容量，先核依赖再清理或轮换缓存

用户明确选择当前双卡AutoDL暂不扩容。继续已批准的完整研究，优先核实并清理项目内废弃、可重建内容，必要时分阶段轮换权重缓存；不得自行购买或扩盘。不能把此选择提升为永久禁止将来扩容。

保留在用模型、T5/VAE/tokenizer、后续训练和只读复用所需数据、所有原始失败与唯一证据。Long全部终态且owned进程和guard清理后，其远端Transformer权重副本才可进入依赖核查与缓存轮换；本机完整原件保留，不能仅凭预计完成时间提前删除。每次清理保存精确清单、来源、可恢复依据、进程身份与实际回收量，不把预计释放量写成已清理。

若核查后仍不足，报告实际容量缺口及哪些任务受限，不降低原质量/完整任务门、磁盘保留线或无记录重置预算来继续执行。
