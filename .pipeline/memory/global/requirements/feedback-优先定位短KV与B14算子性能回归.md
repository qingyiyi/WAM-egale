# 优先查清短KV与B14的算子性能问题

当前算子交付优先定位用户指出的短KV、B14慢点，直接核对固定Torch源码与实际调用链，允许复用其实现。逐点区分attention核心、完整block、模型和计时口径，保留慢点及全部重复数据；不能用平均值掩盖退化，也不能未经测量把性能差异归为某个根因。

用户已澄清比较对象是自有实现相对原Torch的性能退化。固定相同输入、cache、dtype和执行边界定位；B14比B2的绝对耗时增长、普通缓存收益及融合改善幅度不是这个反馈的替代答案。

报告应明确延迟比的分母和方向，将未融合复现版/Torch与融合版/相同配置未融合基线分列。用户关于2.5%是否合理的问句不表示批准放宽旧筛查或数值精度门；没有新统计证据时不把全部差异解释成噪声。

此反馈调整当前检查优先级，不把“所有短KV/B14已证明退化”登记为事实；不改变精度/状态要求、两份代码约束或投机侧禁止修改。仍等待他人GPU任务自然退出，具体作业另设有限预算。
