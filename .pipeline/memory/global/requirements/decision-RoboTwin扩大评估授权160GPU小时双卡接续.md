# RoboTwin扩大评估：160 GPU小时、双卡接续

用户已明确授权在现有BAAI远端两卡启动固定六任务×每任务100有效初态×三臂，共1800完整局。新一期总上限160 GPU小时，包含准备、失败、等待与清理；从登记T0起最长10天，不租新卡。旧M40的24小时账本、绝对截止、PARTIAL和原DEV90永久保留，新账本不重置旧消耗。

FFN profile期间保留GPU0，RoboTwin先用GPU1，随后两卡分片；每组T/TF连续/PF2保持同卡。原目标权重、TF ON3000、阈值、物理、成功判据和数据暴露边界不变，不新增训练或架构搜索。启动前补齐原计划的官方有效初态清单、bank与适配审计，未通过的工程优化不能直接当全面等价。沿既定30episode shard自动接续，阶段性汇报。

此前关于“目标已同意、资源尚未批准”的状态由本条替代。四科学权限不因此放行。本机最多四分之一的分配许可保留，但这次新160 GPU小时授权的默认资源为现有远端两卡，不额外采购。
