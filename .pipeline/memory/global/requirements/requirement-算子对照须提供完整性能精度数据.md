# 算子对照须提供完整、可追溯的数据

用户要求评价自有算子与原版Torch的一致性时，提供尽可能完备的实际性能与精度数据，不能只给一句通过或最好结果。适用于本项目算子验收与后续系统实现对照。

报告须说明源码/二进制版本、参考实现、硬件与计时边界；展示全部已测真实输入、独立进程与重复轮次的延迟、波动和数值误差，并指向原始证据。明确容差一致与逐位一致、算子与block/模型/闭环任务的区别；缺测范围标明未知，历史失败保留。

本要求不自动改变旧验收阈值、不要求伪造未保存的张量统计，也不构成无限GPU预算、打断既定任务或正式性能放行。
