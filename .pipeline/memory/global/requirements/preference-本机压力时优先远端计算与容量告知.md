# 新机承担主要工作，本机按资源补充分担

本轮优先使用当前已授权的新机承担训练、采集和质量评估；本机按实际CPU/GPU条件补充分担，保留轻量代码、HW、调度与文件管理。用户已批准的BAAI迁入安排替代旧偏好仅指AutoDL的表述，不是永久禁用本机GPU，也不恢复连接已归还实例。

在依赖、显存、CPU、状态与端口隔离成立时，将既定可执行任务及时启动、后续自动接续，按资源汇报正在做什么及预计剩余时间；不为占满资源新增无关研究臂。具体case分片、实时负载和ETA属于Cycle/作业证据，不保存为长期事实。同case对照同物理GPU、模型数学/质量门与原总预算保持；独占正式性能另按原权限进行，不能混硬件计时。

容量不足先给当前剩余、所需容量、用途和影响；未经用户明确授权不扩容、购买或新租GPU。项目内清理继续核对依赖和可重建性，保留唯一权重、自然任务失败、原始证据与不可重建数据，不动他人/系统文件。

此偏好只适用于当前Cycle的已授权研究，不追加结构/阈值搜索、独立TEST或正式性能许可。
