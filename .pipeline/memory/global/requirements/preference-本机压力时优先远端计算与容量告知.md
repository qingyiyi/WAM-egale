# 本机压力下优先使用现有AutoDL，容量需求明确告知

本轮新训练、采集、质量和CPU缓存生产优先放现有AutoDL，减少共享本机负载。本机可保留轻量代码、HW、调度及必要文件管理；这不是用户永久禁用本机GPU的新规则。独占正式性能仍遵守原硬件与质量门，本次只调整资源安排，不混SXM/PCIe速度。

若远端或本机容量不足，先给出当前剩余、需要容量、用途和影响，再由用户处理扩容；不自动购买/租用新资源。用户再次允许清理本机废弃项目资源，沿用已有项目内依赖/可重建性核查和授权范围，保留唯一权重、原失败与不可重建证据，不清理他人/系统文件。

迁移未启动的新套件可新登记硬件/CPU分片，旧namespace/准备失败/起点/deadline与四false不改。此决定不追加结构/阈值搜索、测试证书或新的GPU采购授权。
