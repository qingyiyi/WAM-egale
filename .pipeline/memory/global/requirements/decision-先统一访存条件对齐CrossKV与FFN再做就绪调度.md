# 先核对原语与整层开销，再做就绪tile调度

执行顺序：统一真实输入、前序访存和缓存条件核对原语与整层。用户已明确确认当前先解决六个小投影嵌入整层变慢的问题，再继续FFN自身对齐；可在现有optimized内实现并验证固定形状阶段函数，保持数学和同步边界进行比较。主要差距收敛或能给出可追溯解释后，再按真实DAG实现就绪tile补位。首个可提前分支考虑只依赖context的cross K/V。

每个子算子采用合适tile与自然任务数，不要求各阶段都凑108 CTA。改变warp参与或CTA调度时固定其他条件；必须比较完整层，不能把局部改善或线程数量当作整层收益证明。共享内存搬运、写回、资源、同步和访存解释以当前源码、真实输入和测量为据。

用户已批准在M39内继续有限核对与证据支持的优化，无需重复申请同一诊断。沿累计10小时，每个实际作业有界登记，旧起点、失败、消耗和截止保留。按当前源码证据开展有界修改，不同时扩大候选搜索；阶段性结果及时汇报。

改动仅在optimized；baseline、原tile、投机生产与保护文件不动。每次保留候选前验证短/中/长KV、数值和有效状态。已确认机制、临时假说、未知及适用范围分开；不能把寄存器数量等单一指标认定为根因，也不能以调度收益掩盖原语差距。

本决定不扩大RoboTwin窗口，不放行四项科学权限。动态实验数字保存在Experiment，不写成长期约束。此前执行阶段原文见当前M39 remaining-gemm-audit-20261021/PRIOR-ALIGNMENT-DECISION.md和Cycle历史记录。
