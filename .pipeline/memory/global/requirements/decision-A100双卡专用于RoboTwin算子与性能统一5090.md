# A100双卡用于RoboTwin，算子与性能统一5090

现有BAAI两张A100均可持续接续已经批准的RoboTwin固定队列；GPU0不再为算子预留。启动前核对现有worker、唯一pair领取与共享资源账本，三臂同pair同卡，复用优化reset，不重跑已有终态或自动重试失败。

此分工替代此前GPU0临时运行至上午10点/下午14点后归还算子的安排；保留这些旧窗口的终态与账本。原600组/1800局、160GPU小时总上限、原T0与10天绝对截止继续有效，没有新增采购、样本或训练授权。

后续算子开发、精度核对与性能测试统一使用已接入的RTX5090，原A100历史结果保留并标硬件；不跨卡混算速度。5090源码、构建说明、二进制及必要证据继续回同步本机。正式计时仍要求同卡同软件、相同边界及无争用，原数值/质量门和累计算子预算不变。

用户进一步明确两卡应持续运行直至固定评估完整，不能把两个worker退出当作全部完成。已明确的基础设施问题在授权范围内修复并接续，不再按历史临时算子时段停派；补齐使用新namespace/收据，保留旧中断与有效失败。具体作业与一次补齐范围见当前Cycle的resume-after-storage-race-20261024计划；不因此无限追加样本、改变质量门或重置原160GPU小时/10天预算。
