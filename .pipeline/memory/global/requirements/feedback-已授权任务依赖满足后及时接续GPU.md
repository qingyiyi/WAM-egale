# 已批准且依赖就绪的工作及时接续

阶段结果汇报与其他已授权研究可并行。Long收口后，核对真实资源和前序清理，及时推进原已批准的Object、Goal、Spatial固定链；不要把“先汇报Long再讨论”理解成暂停其他套件，也不要重复询问已经明确同意的资源使用。

以原固定工作实际完成吞吐为优化目标：在显存、CPU和状态隔离允许时提高并发，并及时衔接依赖已满足阶段。GPU利用率会随环境/模型交替波动，不为抬高利用率增加无用计算，不保证瞬时100%。

此反馈限当前研究的任务接续安排，不扩展预算、截止、训练条件或测试权限。数据未收齐不能提前训练；新Long调参、独立TEST、正式性能、额外租卡仍受原边界。是否实际启动以进程、READY及真实完整任务记录为准，计划和控制器启动不等于已获得结果。

对已有授权链，定期核实实际自动队列、控制器和空槽交接是否生效，避免已就绪工作因无人操作长期空置；正常自动接续无需用户逐项催促。该要求不意味着自动重试失败、越过数据/清理门、追加新研究范围或延长原截止。临时PID/进度和具体调度周期另存Cycle实测。
