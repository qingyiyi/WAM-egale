# 实验算子代码简洁，核验放到外部

自实现代码应直接呈现单层计算、tile划分、warp分工、数据流和同步，加入适量中文注释。删除重复的输入检查、无效调试计数和不再使用的实验分支，不为生产部署增加额外框架。

精度、有效KV、重复结果和性能比较集中在外部实验脚本，保留真实证据；简化代码不等于取消结果核验。必要的边界掩码、缓存可见性和线程同步属于算法逻辑，应保留。

用户追加决定：先测试简易版，与复杂版同输入对比。有限精度门及无稳定退化对照完成后，用户再次明确“复杂版代码可以删掉了”：后续只维护、讲解和优化简易版，复杂版从活动代码移除；历史源码和实验证据留在归档，不再维护第二份实现。此顺序替代此前“先测复杂版再简化”。仅改optimized及对应实验工具，baseline、投机代码、原tile及保护HW不动。当前单层一个persistent kernel目标不变。

后续顺序固定为简易版测试与注释→单block各阶段同边界性能对照→针对最大差距改进，评估接近原版耗时的可行性；不能仅减少检查就宣布已对齐速度。
