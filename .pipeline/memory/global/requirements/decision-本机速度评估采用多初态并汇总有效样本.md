# 本机速度评估采用多初态，汇总有效样本

用户要求本机速度评测增加初态覆盖，并对没有实施/配对问题的有效结果计算平均值。具体初态清单、顺序、预算与统计公式在新实验登记中先固定；不能将历史单初态结果改称多初态。

沿用项目原证据边界：“有效”按身份、初态配对、完整终态与计时资源条件判断，不能按成功率、速度快慢或长尾事后筛选。原始无效记录保留，给出候选数、准入数、排除原因；完整算法失败与慢成功仍保留。全体有效尝试与双方成功子集分别统计，并明确分母与均值算法。

本条只授权当前目标中的多初态安排，不自动改变旧阈值、四项科学权限、正式性能放行、原六小时绝对截止或其他GPU预算。新panel为已暴露DEV/探索性成本，不冒称独立TEST。

本轮执行优先级已由用户确认：先完成Goal固定多初态完整配对与统计；只有Goal收口后，原窗口剩余预算足以覆盖下一套准备、完整任务及清理时，才推进其余套件。不得为覆盖数量提前分流、减少Goal完整性，不能把此优先级解释为延长原六小时或取消其他套件待办。此项将此前Goal优先的执行假设确认为用户决定。
