# 按5090实际架构能力进行有界优化

当前允许在独立SM120 optimized入口继续优化；TMA是待实测候选，不预设必须有效或采用。先核对5090实际支持的指令、布局、共享内存限制，不能将SM100/B200的专用能力套到SM120。

保持现行逐位精度契约，保留原正确A；逐候选用真实完整block、短中长KV、同条件eager原Torch/guarded比较，按实际融合单元输出完整阶段表及改动和保留/回退理由。预算沿原十小时累计，具体作业有界登记，不扩展训练/机器人/完整DAG，不改变baseline与生产准入。

具体机制、临时假设与性能结果只存实验，不提升为长期事实。

当前优化重点为FFN与Self/Cross输出投影。用户希望用上TMA并使这些阶段的性能接近原Torch；分析可以共用的GEMM实现与调度，不能将此解释为所有形状必须使用同一tile/warp比例，或为了采用TMA放宽精度和性能验收。

10/24用户明确“我同意，你先试试”，替代上一轮仅讨论状态：先有界验证FFN2局部split-K计算并行、按原BF16次序提交，原主循环/tile/四MMA warp固定，暂不叠加TMA改动；通过数值检查后测独立FFN2与三KV完整层。具体作业见ffn-splitk/PLAN.md，原十小时累计不增。是否采用由实际结果决定。

用户在FFN2有限实验汇报后再次同意继续：下一步有界验证Self输出、Cross Q、Cross输出投影的有序K分段调度；先逐位再三KV完整层及完整阶段表。保留FFN2已选版本，暂不同时改TMA或扩DAG；原累计十小时不增。本次授权替代该续项的“仅建议、未启动”状态，结果仅存实验。

用户在讨论输入双缓冲后明确同意实验：先连续TMA K64输入ring跨十个数值段，保持原MMA、BF16分段合并及后处理，不同时加入后处理warp重叠。保留正确A，先精度后完整层/阶段测量，原累计十小时不增。此决定替代本续项仅讨论状态；具体预算和终态见projection-tma-continuous实验。

用户在连续TMA无净收益报告后明确同意：先测输入等待、shared→register/MMA、后处理与同步分量及插桩扰动，再决定是否做后处理warp交接；本轮仅诊断副本，保持当前采用版本，原累计预算不增。此决定替代本续项仅建议状态，结果存projection-tma-components，不自动推进新warp分工。

10/24用户在分量诊断后明确同意先处理TMA发起和输入交接，并要求先解释当前问题、源码和处理方案。当前优先保留八个MMA warp及原数值顺序，暂不叠加输出/后处理warp分工。此决定替代上一阶段输入交接仅为建议的状态；具体实现、正确性和收益仍须分别验证，原累计十小时预算不增。源码分析本身不启动GPU作业，当前采用版本不因同意研究方向而自动替换。

用户2026-10-24明确同意实际试验四MMA＋一TMA＋三epilogue局部分工，替代本续项仅讨论与八MMA固定限制。仅三个投影，在原累计余量内先有限逐位/状态，再三KV完整层与全阶段表，不同时开启六warp或动态寄存器分配候选。是否采用以实际完整层结果为准，当前正确A保留。具体作业见projection-warp-specialized/PLAN.md。
