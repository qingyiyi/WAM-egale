# 先逐阶段对齐原版性能，再做异步调度

当前单层仍按阶段同步，先使用相同真实输入、数值边界与计时边界，核对每阶段原版、优化版独立执行和嵌入整层的差异。由此区分阶段原语成本与persistent整层资源、调度和等待成本，再决定如何优化。

先保留已有计时和精度证据；不能把插桩阶段耗时除以原版单kernel耗时直接作为正式差距。先逐阶段定位、收敛主要差距，再评估跨阶段ready填尾波；不是要求所有阶段零误差计时或允许改变数学契约。

baseline、投机代码和原tile不修改，优化仍在optimized。此反馈改变优先顺序，不扩展到30层、正式机器人性能或无限GPU预算。具体新增作业仍须有界登记。
