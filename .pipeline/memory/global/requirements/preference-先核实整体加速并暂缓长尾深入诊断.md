# 先确认整体计算收益和计时边界

当前优先明确投机的整体计算收益、测量边界与独占复测准备，暂缓对少量慢成功长尾增加深入实验投入。已有长尾分析、正常完整失败、成功率和长度分布继续保留，不能以暂缓诊断解释为删除案例或放宽旧质量门。

质量评估沿已登记并行任务继续。按现有授权保存有容量上限的代表性真实输入和必要状态，再在无争用窗口测量与保存边界相符的推理成本；不默认actions/latents或部分缓存已构成完整fixture。采集失败、未核验布局/KV/RNG时明确缺口，不把计划写成完成。

分别说明单次action去噪、完整policy/chunk推理、完整机器人episode和cold/warm边界。完整输入重放可用于对应的推理pipeline；机器人任务E2E仍需各方法从配对初态自然闭环运行。不能把其他论文的预测延迟倍数直接当成本项目全任务倍数。

此偏好只改变当前分析投入顺序，不授权新训练、重复既有episode、架构搜索或大融合，不自动打开原受阻的正式性能入口、不改变四项false。新GPU作业仍按已有范围、质量/资源门和预算登记。
