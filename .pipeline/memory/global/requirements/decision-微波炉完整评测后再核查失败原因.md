# 微波炉完整评测后再核查失败原因

沿现有固定队列继续，等 open_microwave 的100个有效初态、Target/TF连续/TF+PF2共300局均有完整终态后，再进行该任务原因核查。用户没有要求提前停队列、重排任务或更换配方；其他任务继续沿原授权接续。

先检查原Target与官方对应任务的复现差距，再检查同初态Target成功而TF/PF2失败，以及PF2救回/损失的配对。使用实际已有日志确认初态、模型随机流、动作映射、环境命令、成功判据及可获得的失败阶段证据；区分观察、假设与未知，不把未保存tensor当作可重放证据。

原160 GPU小时、10天截止、权重/阈值/成功判据和全部失败保留。这条顺序决定不自动授权新增训练、扩大样本或无界GPU重跑。CPU完成提醒读取现有终态即可；若原资源边界先到而未齐，记录PARTIAL和缺项，不自行延长。

完成提醒只代表完整结果已可分析，不代表失败根因已确定，也不承诺会话离线时主动推送消息。
