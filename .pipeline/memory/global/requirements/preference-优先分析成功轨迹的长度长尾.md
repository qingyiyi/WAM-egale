# 当前优先分析成功局的轨迹长尾

用户当前希望把研究注意力放在少数成功但执行很慢的轨迹，给出同task/init下Target与对应投机方法均成功时的实际环境动作数、长度比分布、超限数量及具体案例；单独分析多出的policy chunk与动作行为。

这细化当前质量分析和汇报重点，不表示成功率门已通过，也不放宽原长度、非劣性或正式性能要求。完整自然失败仍计原成功率/800罚分，基础设施PARTIAL另列。成功子集、去尾敏感性与全体主表并列，不能以删除长尾替代全样本结果或把事后子集称为独立测试。

临时分布、task/init名单、去尾耗时和物理原因假说保存在实验报告，不提升为用户决定。此偏好不授权新增训练、episode重跑、阈值调整、按task硬编码回退或未放行的正式性能；既定完整研究继续。
