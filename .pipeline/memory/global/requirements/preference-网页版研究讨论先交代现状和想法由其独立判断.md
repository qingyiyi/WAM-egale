# 网页版先得到真实背景，再独立判断方向

在本轮算子研究的网页版讨论交接中，先说明可追溯现状、已测结果与限制，再单独转述用户尚未定案的想法和待判断问题。让网页版独立决定方向和优先级，允许质疑、否定或调整顺序，不把助手偏好的静态/动态/混合方案或某个原型预设为应采纳结论。

用户此次要的是评议和拿主意；不要擅自改成要求立即完成详细架构、伪代码、固定交付清单的实现任务书。若用户以后明确请求详细设计，则按新请求处理。当前DAG、入度和QKV交错思路仍未定案，不记录为已批准实现，不增加GPU或其他执行权限。
