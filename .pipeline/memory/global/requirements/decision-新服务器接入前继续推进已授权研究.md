# 新机未接入期间继续有用工作，保留可暂停接续边界

用户明确允许尚未提供新服务器期间继续推进已有授权范围内可执行的工作。先完成已收尾阶段的备份、结果统计与迁移准备；资源可用时可用独立新namespace接续尚未开始的完整任务组，按小批次设置阶段边界，收到新机连接信息后完整组收尾再切换。

不重启已终态旧job，不重跑已完成或失败的任务，不覆盖旧暂停、PARTIAL、FAILED及预算账本。已冻结结果保持来源身份，接续按完整case去重，各臂同卡，硬件与并发阶段分别记录。新任务与备份快照隔离，不能改变正在回传的原件。

沿用现有机器和原研究预算/绝对截止，不自动购买、续租、扩盘或扩大实验范围。所有臂继续优化reset；不smoke、独立测试或SHA，不修改阈值、质量门及四false。此前[阶段暂停换机决定](decision-旧AutoDL阶段收尾暂停并准备换机.md)的已执行收尾和证据保护保留，仅不再要求无新机时停止一切后续有用工作。
