# 评测尽可能迁往新机，本机用于算子研究

当前阶段将已授权的质量评测和采集尽可能转到现有BAAI新服务器；本机不再自动接续新的Object全量评测。正在运行的本机完整episode按自然终态收尾后释放GPU，再迁移未开始工作和必要数据，避免截断或重复计数。新机仍仅在 `~/cxz` 内工作，不租新卡、不杀他人进程。

用户明确批准在本机补齐算子数据：原始输入规模与实际verifier输入规模，分别覆盖短/中/长KV的性能和精度。使用真实输入、同版本Torch对照、清楚的布局/共享范围与计时边界；不能用随机或虚构输入替代，也不能把B14的7候选写成互相注意的Q112。

本轮应持续低频监控本机资源，等待其他用户作业自然结束；已批准算子任务满足资源条件后直接启动，不再重复询问。一次CPU等待器超时不能被误报为任务完成，仍需维护明确的待办与接续状态。用户关于当前空闲的说明触发即时资源核验，不代替实际占用记录或扩大实验范围。原预算、截止和自有清理要求继续有效。

正式计时仍需无争用。本要求不修改原质量门或放行正式TF任务性能，不恢复已撤回融合，不修改原tile实现；新测试使用独立namespace和明确资源上限。迁移的资源增量、匹配Target重测和原预算分别记账，不能重置旧账本或冒充新增独立初态。
