# 失效产物可清理，正确执行的失败任务仍是有效数据

程序、环境、迁移或基础设施错误造成的无效产物，在核实归属、依赖与不会影响在跑作业后可删除；不把失败目录一概当废弃项。若在跑审计或后续预算/来源核验仍引用原件，先标记待清理并完成依赖迁移，再删除冗余大文件，保存必要的轻量错误原因、attempt身份、实际资源消耗与删除清单，不补造原收据。

正常执行到自然终态但机器人没有完成任务，是正确有效的算法失败，保留并计入成功率和800罚分。用户的空间清理要求不能解释为只保留成功局、覆写旧FAILED/NO_GO或将四项false变true。原tile/保护文件及非项目内容不在清理范围。
